# Week 4 Assessment Overview — Production Planning and Scheduling Analysis in SAP SCM

## Assessment focus
This repository contains the Week 4 internship assessment on production planning and scheduling in SAP SCM. The work connects demand, finite capacity, master data, PP/DS planning, bottleneck analysis, scheduling simulation, disruption recovery, and KPI monitoring.

## Visual documentation
The diagrams/ folder contains the production-planning flow and bottleneck-recovery logic. The final report also contains the simulated planning-board view and capacity analysis.

## Repository standard
The six-assessment series uses a consistent structure: a root README, the final assessment and supporting analysis under docs/, and editable process diagrams under diagrams/. Where a structured dataset is useful, it is stored separately under data/.

## Scope note
The production quantities, capacity calculations, bottleneck results, recovery actions, and SAP planning views are illustrative learning simulations and are not claims of live production execution.
